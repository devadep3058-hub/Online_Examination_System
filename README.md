
# Online Examination System

## About the Project
The Online Examination System is a console-based application
developed using Python and Object-Oriented Programming.

It allows students to attend multiple-choice examinations
and receive automatically calculated results.

## Features
- Student name registration
- Multiple-choice questions
- Interactive examination
- Automatic score calculation
- Percentage calculation
- Pass/Fail result generation

## Technologies Used
- Python 3
- Object-Oriented Programming

## OOP Concepts
- Classes and Objects
- Constructors
- Encapsulation
- Methods

## Project Files
- main.py - Main application
- question.py - Question management
- exam.py - Examination and result calculation
